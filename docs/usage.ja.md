## 1. 初回ログイン

インストール完了後、管理コンソールを開きます:

- ワンクリックインストール / Docker: `http://localhost`
- ローカル開発: `http://localhost:8789`

インストーラーで設定した管理者のユーザー名とパスワードでログインします。ログイン後はダッシュボードが表示され、8 つの KPI 指標カード（総費用、インプレッション、クリック、コンバージョン、CTR、CVR、平均 CPC、平均 CPA）、日次費用トレンドの折れ線グラフ、プラットフォーム比較の棒グラフ、TOP10 キャンペーンを確認できます。

パスワードやアカウント情報の変更: システム管理 → ユーザー管理。

## 2. プラットフォーム認可

システムは**国内 16 プラットフォーム + 国際 13 プラットフォーム**をサポートしており、すべて「アカウント管理 → アカウント連携」から認可します。

### OAuth2 プラットフォーム（大半）

1. 「アカウント連携」ページで対象プラットフォームを選択し「認可」をクリック
2. ブラウザがプラットフォームのログインページへリダイレクトされ、ログインしてアクセスを承認
3. コールバック後、システムが Access Token を自動保存

認可済みプラットフォームはアカウント一覧に表示されます。期限切れトークンは `TokenRefreshTask` が自動更新します（毎時 55 分）— 手動操作は不要です。

### API Key プラットフォーム

360、搜狗、友盟などのプラットフォームは API Key 認証を使用します:「アカウント連携」ページで API Key（および署名パラメータ）を手入力して保存すると、同期が始まります。

> 国内 16 プラットフォーム: 巨量引擎（Ocean Engine）、百度营销、淘宝/阿里妈妈、腾讯广告、快手磁力引擎、小红书蒲公英、微博粉丝通、B站花火、优酷广告、美团广告、知乎广告、360推广、搜狗推广、友盟、京东京准通、拼多多广告
>
> 国際 13 プラットフォーム: Google Ads、YouTube Ads、Meta Ads、TikTok Ads、LinkedIn Ads、Snapchat Ads、Pinterest Ads、Twitter/X Ads、Amazon Ads、The Trade Desk、Spotify Ads、Twitch Ads、Netflix Ads

## 3. アカウント連携と素材ライブラリのアップロード

### アカウント管理

プラットフォーム認可後、アカウントは「アカウント管理」一覧に表示されます。各アカウントは同期に参加するかどうかを個別に制御できます（`sync_enabled`）。広告階層はキャンペーン → 広告グループ → クリエイティブの 3 段階です。

### 素材ライブラリ

「素材ライブラリ」では画像・動画のアップロードとギャラリー表示ができ、広告クリエイティブで参照できます。アップロードした素材はオプションで CDN ストレージを利用できます（下記参照）。

### CDN ストレージプロバイダーの設定

システムには複数ドライバー対応のストレージ抽象層が組み込まれており、複数のプロバイダーを同時に設定できます:

| ドライバー | 説明 |
|-----------|------|
| ローカルストレージ | デフォルト。サーバーディスクに保存 |
| 阿里云 OSS | AlibabaOssStorage |
| 腾讯云 COS | TencentCosStorage |
| S3 互換 | S3CompatibleStorage（AWS S3、七牛云、MinIO などに対応） |

「CDN プロバイダー」ページでプロバイダーを追加し、対応するキー・リージョンなどを入力すると有効になります。

### 署名付きアップロードとキャッシュパージ

- **署名付きアップロード**: サーバーがアップロードごとに期限付きの署名付き URL（OSS/S3 の PUT）を発行し、ブラウザやモバイルクライアントがアプリケーションサーバーを経由せずオブジェクトストレージへ直接アップロード — 帯域と負荷を軽減
- **キャッシュパージ**: 素材の更新・削除後、CDN キャッシュパージを実行でき、クライアントは常に最新コンテンツを取得できます

## 4. データ同期

同期は 6 つの定期タスクで駆動されます（webman crontab プラグインがプロセス内でスケジュール — 外部 crontab は不要）:

| タスク | 頻度 | 役割 |
|--------|------|------|
| RetrySyncTask | 3 分ごと | 前回失敗した同期を再試行 |
| AlertCheckTask | 5 分ごと | アラートルールを評価 |
| DataSyncTask | 10 分ごと | キャンペーン/広告グループ/クリエイティブとレポートを同期（過去 2 日分、9 指標） |
| BidCheckTask | 10 分ごと | 自動入札ルールをチェック |
| BudgetCheckTask | 15 分ごと | 予算アラートをチェック |
| TokenRefreshTask | 毎時 55 分 | 期限切れプラットフォームトークンを更新 |

タスク設定は `service/plugin/ads-task/config/cron.php` にあり、頻度はそこで変更できます。同期状態は「データ同期」ページで確認でき、アカウントごとの ON/OFF は「アカウント管理」にあります。

## 5. レポート分析

### ダッシュボード

8 つの KPI 指標カード + 日次トレンド折れ線グラフ + プラットフォーム比較棒グラフ + TOP10 キャンペーン。日付範囲フィルターとワンクリック PDF/Excel エクスポートに対応。

### カスタムレポート

- **ディメンション**: date、platform、campaign
- **指標**: cost、impressions、clicks、conversions、ctr、cvr、cpc、cpm、roi
- ディメンションの組み合わせクエリと並び替えに対応

### アトリビューション分析

組み込みのクロスプラットフォームアトリビューションエンジンは**5 つのアトリビューションモデル**（first_touch、last_touch、linear、time_decay、position_based）をサポートし、30 日間のルックバックウィンドウを持ちます。「アトリビューション分析」ページでモデルと日付範囲を選ぶと、各チャネルの貢献度を確認できます。

### キャンペーンカレンダー

「キャンペーンカレンダー」は各キャンペーンの配信スケジュールをカレンダービューで表示し、日々の配信ペースを一目で確認できます。

### エクスポート

レポートは 3 つのエクスポート形式に対応:

- **CSV**（UTF-8 BOM、Excel で文字化けせずに直接開けます）
- **Excel**（HTML .xls）
- **PDF**（HTML 印刷レイアウト）

## 6. アラートと通知

### アラートルール

「アラートルール」ページでルールを作成: 監視対象（予算/費用/インプレッション/クリックなど）、しきい値と比較方法、有効範囲、通知チャネルを選択します。有効なルールは `AlertCheckTask` が 5 分ごとに評価し、条件に一致すると発動します。

### 通知チャネル

| チャネル | 説明 |
|---------|------|
| Web | アプリ内通知。「通知センター」で確認 |
| Email | メール送信（SMTP、`mail()` フォールバック）。アラートルールで受信先を設定 |
| SMS | ショートメッセージ送信 |
| Webhook | 設定したコールバック URL へ JSON を POST。企業微信/钉钉/飞书 などと連携可能 |

アラート履歴は「アラート記録」ページで確認できます。

## 8. マルチテナント

システムには組み込みのマルチテナントプラグイン（ads-tenant）があります:

- **テナント識別**: `TenantIdentify` ミドルウェアがリクエストごとに現在のテナントを識別
- **データ分離**: 2 つのモード — 共有データベースを `tenant_id` で分離、またはテナントごとに独立データベース（`db_type`）
- **クォータ管理**: `QuotaService` がテナントのクォータ（アカウント数、素材数など）を検証し、超過リクエストは拒否
