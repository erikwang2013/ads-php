Genera nuevos adaptadores de plataformas publicitarias siguiendo el patrón establecido de la interfaz `PlatformAdapter`.

## Patrón

Los 29 adaptadores viven en `service/plugin/ads-platform/adapter/`. Cada uno implementa `PlatformAdapter` con 14 métodos.

## Reglas

1. **Dinero**: Convierte todas las monedas de la plataforma a fen (分) en el transformador de valores
   - YUAN → ×100, micro-dólares → ÷10000, centavos → sin conversión
2. **Estado**: Mapea los códigos de estado de la plataforma a `enabled`/`paused`/`deleted`
3. **CTR/CVR**: Convierte porcentajes a decimales (÷100 si la plataforma devuelve %)
4. **Paginación**: Usa el patrón Generator, comprueba `!empty($list)` para hasMore
5. **Manejo de errores**: Comprueba `curl_errno($ch)` para errores de red, el estado HTTP y el campo de código de la API
6. **Patrones de autenticación**: Cabecera Bearer / access_token en URL / cabeceras personalizadas con firma

## Registro

Añade a `service/plugin/ads-platform/config/bootstrap.php`:
```php
use plugin\ads_platform\adapter\PlatformName;
AdapterRegistry::register(new PlatformName());
```
